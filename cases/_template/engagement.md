# 案例模板：项目概况（engagement）

> 复制本文件到 `cases/<your-case>/engagement.md` 并填写。**遵守 cases/README.md 的脱敏规则。**

## 一、主体画像（脱敏）
- 主体代号：集团A（禁止真实名称）
- 行业类别：如 农批市场集团 / 地方国企 / 线下平台型集团
- 规模档：如 营收百亿级 / 员工千人级（**量级，非绝对值**）
- 数据现状初判：系统数量级、数据体量量级

## 二、本次交付范围
- 覆盖工序：汇 / 存 / 治 / 管 / 服 / 用 / 模（勾选）
- 覆盖技能：dx-data-baseline / dx-architecture-opt / dx-data-quality / dx-application-plan ...
- 交付周期：如 6 周
- 交付物清单：（列出，脱敏）

## 三、约束与边界
- 时间/预算/组织约束
- 已知敏感区（哪些数据不能碰）
- 关键干系人角色（**只写角色，不写姓名**）：如 董事长 / CIO / 财务负责人

## 四、结果概览
- 量化成果（可用相对值，如"覆盖率从 X% 提升到 Y%"）
- 采用情况：被采纳 / 部分采纳 / 未采纳
- 后续演进
