## 一、立项信息（8 问，本例答案）

| # | 问题 | 本例回答 |
|---|---|---|
| 1 | 主体画像 | 农产品流通集团，地方国企，集团型（含 6 家下属市场公司） |

| 8 | 验收标准 | 场景地图 + 产品清单 + 入表路径 + 董事长汇报材料 |

## 二、关键纪律（本技能的执行要点）

**顺序**：先读上游 → 再画场景 → 再设计产品 → 再算价值 → 最后入表 → 收口汇报。
**铁律**：先价值后技术；对外用量级不做绝对承诺；每个"不做的事"要写原因。

**门禁（上游必须齐）**：
- [x] 摸底四件套（系统清单/资产清单/数据流图/DCMM 分）
- [x] 架构三件（蓝图/路线图/治理卡口表）
- [x] 质量三件（指标字典/所有权清单/质量规则集）

> 若上游缺失 → 本技能应**拒绝开工**，提示回退补上游。本例为演示，已虚构齐全。
